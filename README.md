# Sara Iravani — DevOps & Platform Engineer

I’m a DevOps / Platform Engineer based in Toronto, Canada, with experience supporting cloud infrastructure and Kubernetes platforms, CI/CD pipelines, infrastructure as code, observability, and platform security.

This repository contains my professional portfolio: selected case studies from my engineering experience and technical writing focused on practical platform and reliability challenges. The site is a work in progress, and I’m continuing to refine the content.

## Focus areas

- **Cloud & infrastructure:** AWS, Amazon EKS, Terraform, VPC, IAM
- **Containers & platforms:** Kubernetes, Docker, Helm, Rancher
- **CI/CD & automation:** Jenkins, Bamboo, Bitbucket, GitHub Actions, Ansible
- **Observability & reliability:** Prometheus, Grafana, troubleshooting production workload issues
- **Security practices:** RBAC, NetworkPolicies, image scanning, workload identity

These technologies reflect different parts of my work history and are not necessarily used together in a single environment.
